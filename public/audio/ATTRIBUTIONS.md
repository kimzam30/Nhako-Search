# Audio Attributions

The ambient tracks used in this project are dynamically synthesized approximations of CC0 / Public Domain concepts, created for this prototype.

- `lofi.mp3`: Synthesized warm drone (CC0 / Public Domain)
- `rain.mp3`: Synthesized white noise (CC0 / Public Domain)
- `wind.mp3`: Synthesized pink noise approximation (CC0 / Public Domain)
- `birds.mp3`: Synthesized high-frequency bursts (CC0 / Public Domain)

All audio assets are free for commercial and non-commercial use with no attribution required.
